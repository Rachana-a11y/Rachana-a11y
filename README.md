## 👩‍💻 About Me

<img align="right" src="https://media.giphy.com/media/M9gbBd9nbDrOTu1Mqx/giphy.gif" width="240" />

**Cybersecurity Analyst | SOC L1 Analyst** &nbsp;·&nbsp; she/her &nbsp;·&nbsp; 🇮🇳 India

I'm **Rachana Appani**, a passionate cybersecurity professional with hands-on internship experience in **SOC operations, threat detection, log analysis, and vulnerability assessment**. I approach security from both offensive and defensive angles — because understanding how attackers think makes me better at defending.

Currently building real-world tools around **Cyber Threat Intelligence**, **SIEM/EDR workflows**, and **Vulnerability Scanning**.

<br/>

- 🔐 &nbsp;**Red Team / Bug Bounty** — Recon, exploitation & web app security testing
- 🛡️ &nbsp;**SOC L1 / Blue Team** — Wazuh SIEM/EDR, log analysis & threat detection
- 🕵️ &nbsp;**Threat Intelligence** — IOC enrichment, CTI dashboards & threat hunting
- 🧠 &nbsp;**OWASP Top 10** — Deep web application security expertise
- 🏆 &nbsp;**EC-Council CCEP Certified** — Certified Cybersecurity Entry Professional
- 📦 &nbsp;**Key Projects** — CTI-Dashboard, VulnVision-360, SOC_EDR, NetScopePro
- 🌱 &nbsp;**Currently learning** — Cloud security (AWS), advanced malware analysis
- ⚡ &nbsp;**Fun fact** — I debug with ☕ and defend networks with determination!
